# Standard Peripheral Library (SPL)

Separate Libraries for STM8S and STM8L lines.

Cosmic / Raisonance / IAR official support.

SDCC community ports.

## Versions

* STM8S & STM8A: **STSW-STM8069** (V2.3.x) supports Mainstream (STM8S003, S103, S105) & Automotive (STM8A)
* STM8L15x / 16x / 05x: **STSW-STM8016** (V1.6.x) Low-power devices, EnergyLite
* STM8L10x : **STSW-STM8012** (V1.2.x) Ultra-low-power entry line
* STM8TL5x: **STSW-STM8030** (V1.0.x)
