# STM8S-DISCOVERY

Eval board with STM8S105C6 MCU.

* 32K Flash
* 2K RAM
* 1K EEPROM
* 5v or 3.3v
* User LED
* Touch Sensor

## Toolchains

* Cosmic/STVD/Visual Studio
* SDCC
